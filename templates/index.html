系統測試與說明

選擇要測試的目標頻道並點擊按鈕，即可立即發送測試卡片至您的 Discord 或 LINE。

如何讓「不同頻道」接收「不同訊息」？

  1. 在您的 Discord 私人伺服器中，建立不同文字頻道（例如：#大盤暴跌警報、#etf進場訊號、#每日長線精選）。
  2. 對每個頻道分別點 「編輯頻道」→「整合」→「Webhook」→「新 Webhook」→「複製 Webhook 網址」（每個頻道都會有自己獨立的網址）。
  3. 將對應頻道的網址貼入左側「分頻道推播設定」中（沒貼的類型會自動退回發送到最上方的「預設頻道」）。
  4. 通知靜音小技巧：可將 #大盤暴跌警報 的 Discord 頻道通知設為「所有訊息」響鈴提醒；#每日長線精選 設為靜音，想看時再點進去瀏覽，完全不互相干擾！
  5. Render 永久保存提醒：建議同時將對應的環境變數（DISCORD_WEBHOOK_URL / DISCORD_WEBHOOK_MARKET / DISCORD_WEBHOOK_SIGNAL / DISCORD_WEBHOOK_DAILY）加入 Render 後台的 Environment Variables，跨版本更新不遺失。
